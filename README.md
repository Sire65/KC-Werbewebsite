# KC-Werbewebsite

Offizielle Website-Vorbereitung für den Köcheclub Werne.

Enthalten sind öffentliche Website, Clubchronik, Rezepte & Wettbewerb, Mitgliederzugang-Vorbereitung, Kontakt, Aufnahmeantrag, Impressum und Datenschutz.

**Status:** Vor Veröffentlichung müssen Domain, echte Kontaktdaten, finale Rechtstexte, Bilder und der produktive Mitglieder-Login ergänzt bzw. geprüft werden.

Köcheclub Werne — Kochkultur seit 1991.
